## Step 1: Run Baseline Evaluation

```bash
cd apps/orchestrator
python -m evaluation_framework
```

**Output:**
- Logs to console
- Creates `test_results.json` with full results
- Takes ~2-3 minutes

**What happens:**
1. For each of 5 test brands:
   - Loads brand memory (identity, audience, history)
   - Calls your current `generate_daily_concepts` prompt
   - Collects Claude's generated concepts
   - Evaluates against golden standards
   - Scores across 5 dimensions

2. Calculates summary metrics:
   - Average overall score across all brands
   - Average quality, diversity, approval alignment

## Step 3: Identify Improvement Areas

Look at the summary metrics:

| Metric | Target | If Low | Action |
|--------|--------|--------|--------|
| `avg_overall_score` | 0.80+ | <0.70 | Prompt may be too vague |
| `avg_quality` | 0.80+ | <0.75 | Concepts lack detail/relevance |
| `avg_diversity` | 0.75+ | <0.65 | Add emphasis on "genuinely different" |
| `avg_approval_alignment` | 0.70+ | <0.60 | Add approval history weight to prompt |

### Common issues and fixes:

**Problem: Low quality (avg_quality < 0.75)**
- Concepts lack specificity or detail
- Prompts too short or vague
- Missing brand context

**Fix in prompt (claude_orchestrator.py:134):**
```python
# Add emphasis on detail and specificity:
"The 'prompt' field must be a detailed, standalone image-generation prompt 
(100-150 words) describing the actual scene. Include specific details: 
composition, lighting, mood, colors, textures, and what the image conveys."
```

**Problem: Low diversity (avg_diversity < 0.65)**
- 3 concepts are variations of same idea
- Not using different pillars/products
- Headlines too similar

**Fix in prompt:**
```python
"These must NOT be 3 stylistic variations of one idea — each concept 
should be genuinely different in subject, mood, or angle. If possible, 
vary the content_pillar and/or product across the three concepts."
```

**Problem: Low approval alignment (avg_approval_alignment < 0.60)**
- Concepts ignore what reviewers approved
- Not avoiding rejected patterns
- Missing historical context

**Fix in prompt:**
```python
"Critically, use the approval history: lean heavily into what reviewers 
have approved before (look at the approved notes for patterns and themes). 
Actively steer away from anything a rejection note called out."
```

## Step 4: Modify the Prompt

Edit the `instruction` variable in [claude_orchestrator.py:134](../orchestrator/claude_orchestrator.py#L134)

Example improvement:

```python
instruction = f"""You are the concept-planning step for an automated brand content generator.

{context}

TASK
Generate exactly THREE distinct content concepts for today. These must NOT be 
3 stylistic variations of one idea — each concept should be genuinely different 
in subject, mood, or angle while remaining authentic to the brand.

Ground the headline, rationale, and prompt for each concept in the brand identity, 
audience, visual identity, tone, avoid-lists, and AI-behaviour settings above. 

CRITICALLY: Use the approval history — lean into what reviewers have approved, 
and steer away from rejected patterns.

The "prompt" field must be a detailed, standalone image-generation prompt 
(100-150 words) describing the actual scene with specific composition, lighting, 
mood, colors, and details.

Return ONLY valid JSON...
"""
```

## Iteration Cycle

```
Run Evaluation
     ↓
View Results
     ↓
Identify Weak Area (quality? diversity? alignment?)
     ↓
Modify Prompt
     ↓
Re-evaluate
     ↓
Metrics improved? → YES → Continue iteration
     ↓ NO
Revert, try different approach
```

## What the Scoring Measures

### Structural Quality (0-1)
- ✓ Valid JSON format
- ✓ All 5 required fields present (headline, prompt, rationale, content_pillar, product)
- ✓ Fields have minimum content length

### Headline Quality (0-1)
- Specificity: Does it describe a concrete idea, not generic?
- Engagement: Would it catch attention?
- Relevance: Does it fit the brand and audience?
- Grammar: Proper punctuation and tone?

**Target:** 0.80+

### Prompt Quality (0-1)
- Word count: 100-150 words (sweet spot for image generation)
- Specificity: How many detail markers (style, color, light, mood, etc.)?
- Feasibility: Avoids impossible requests (writing text, explaining things, etc.)

**Target:** 0.80+

### Brand Faithfulness (0-1)
- Uses referenced pillars/products in the actual prompt text
- Avoids banned words and visual elements
- Respects photography style and tone preferences
- Aligns with creativity/consistency/diversity sliders

**Target:** 0.80+

### Rationale Quality (0-1)
- Explains why this concept works for the brand
- Minimum 20 characters of explanation

**Target:** 0.90+

### Diversity Score (0-1)
- Do 3 concepts use different pillars/products?
- Do headlines have low word overlap?
- Are subjects/moods/angles genuinely different?

**Target:** 0.75+

### Approval History Alignment (0-1)
- Does prompt text reflect approved themes?
- Avoids patterns that were rejected?
- Shows learning from historical decisions?

**Target:** 0.70+

## Success Criteria

Prompt is ready when:
- ✓ `avg_overall_score` ≥ 0.80
- ✓ `avg_quality` ≥ 0.80
- ✓ `avg_diversity` ≥ 0.75
- ✓ `avg_approval_alignment` ≥ 0.70
- ✓ Per-brand scores are consistent (no brand with <0.70)
- ✓ Per-concept feedback shows no major issues

## Troubleshooting

**Error: "Claude response contained no text block"**
- API issue, retry

**All scores very low**
- Prompt may be too vague or not grounding concepts
- Check that context is being properly formatted
- Verify approval history is included

**Diversity always low**
- Prompt may need explicit pillar/product variety guidance
- Try: "Concept 1 should leverage pillar X, concept 2 pillar Y, concept 3 product Z"

**Prompt quality stuck at 0.6**
- May need explicit word count requirement
- Add: "Respond with exactly 100-150 word prompts, including specific details"

**Brand faithfulness issues**
- Check if prompt is emphasizing brand voice/tone
- Verify avoid-lists are being respected
- May need more examples of brand personality
